# Onboarding gate, and "start from scratch" means documented defaults

The app previously rendered straight into the bundled example schema on every first visit, with no explicit choice between importing a file and starting fresh — which is also what surfaced the `.modal-overlay[hidden]` CSS bug (the export-confirm dialog painted before any button was clicked, since it was the only overlay in the DOM). We added a blocking onboarding screen, shown only when `localStorage` has no persisted `values`/`customSchema` (so reloads with existing edits are unaffected). Critically, "start from scratch" populates every parameter with its documented `default`, not the bundled example's shipped `value` — those differ for several parameters (e.g. `MultiplierConfig.Global` ships at `2.0` vs. documented default `1.0`). The ~49 parameters with no documented default fall back to the bundled example's value, since there's no other valid value to export. Search, Export, and Load-file are disabled while onboarding is showing, since none are meaningful before a schema choice is made.
